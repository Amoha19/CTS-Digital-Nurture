1. angular.json
Contains the Angular project configuration such as build options, assets, styles, scripts and project settings.

2. tsconfig.json
Main TypeScript configuration file for the project.

3. tsconfig.app.json
Contains TypeScript compiler settings specifically for the Angular application.

4. package.json
Stores project information, dependencies and npm scripts.

5. src/main.ts
Entry point of the Angular application. It bootstraps the application.

6. app.config.ts
Contains application-wide configuration such as providers and routing.

7. app.component.ts
Root component of the Angular application.

8. index.html
Main HTML page where the Angular application is loaded.
