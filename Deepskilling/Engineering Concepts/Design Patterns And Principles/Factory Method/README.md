# Factory Method Pattern Example

## Objective
To implement the Factory Method Design Pattern in Java.

## Pattern Used
Factory Method Pattern

## Classes
1. Document
2. WordDocument
3. PdfDocument
4. ExcelDocument
5. DocumentFactory
6. WordFactory
7. PdfFactory
8. ExcelFactory
9. FactoryTest

## Description
The Factory Method Pattern is used to create different types of documents without exposing the object creation logic to the client.
